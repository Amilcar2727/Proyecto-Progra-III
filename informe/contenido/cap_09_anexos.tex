\section*{Anexo A: Estructura del Repositorio}

El código fuente completo del proyecto se organiza de la siguiente forma:

\begin{verbatim}
Proyecto Primer Parcial/
|-- main.py                     # Punto de entrada de la aplicacion
|-- config.py                   # Constantes y parametros globales
|-- requirements.txt            # Dependencias Python
|-- README.md                   # Instrucciones de instalacion y uso
|-- .gitignore
|-- core/
|   |-- modelos.py              # Dataclasses: Nodo, Arista, Grafo, Pedido
|   |-- geo.py                  # Formula de Haversine
|   +-- gestor_datos.py         # Carga/guardado de datos JSON
|-- algorithms/
|   |-- greedy.py               # Seleccion Greedy y vecino mas cercano
|   |-- divide_venceras.py      # Merge Sort y combinacion de rutas
|   |-- dinamica.py             # Knapsack 0/1 y Held-Karp (TSP exacto)
|   +-- backtracking.py         # DFS con poda para rutas bloqueadas
|-- gui/
|   |-- app.py                  # Ventana principal y notebook de pestanas
|   |-- tab_mapa.py             # Pestana de visualizacion del grafo
|   |-- tab_pedidos.py          # Gestion de pedidos
|   |-- tab_algoritmos.py       # Ejecucion de algoritmos
|   |-- tab_comparacion.py      # Graficos de benchmarking
|   +-- canvas_fallback.py      # Canvas offline sin tiles de mapa
|-- data/
|   |-- nodos_cusco.json        # 20 nodos georreferenciados de Cusco
|   |-- pedidos.json            # 30 pedidos de muestra
|   +-- repartidores.json       # 3 repartidores con capacidades
|-- benchmarks/
|   +-- benchmark.py            # Script de medicion de tiempos
+-- tests/
    |-- test_greedy.py
    |-- test_divide_venceras.py
    |-- test_dinamica.py
    +-- test_backtracking.py
\end{verbatim}
